## Publish with GitHub Pages
1. Push this folder's contents to a repository (e.g. `username.github.io`).
2. Settings → Pages → Source: `main` branch, `/ (root)`.
3. The site goes live at `https://username.github.io/`.

`index.html` is self-contained; `assets/` holds the CV download and photos.
